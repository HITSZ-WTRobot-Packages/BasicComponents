# Ethernet PHY Core

`EthernetPHY::Core` 定义同步 PHY 契约 `IPhy` 与链路配置、状态、结果类型，不依赖 RTOS，不创建线程、不做后台重试。逐方法与字段契约见 [IPhy.hpp](IPhy.hpp) 的 Doxygen。

## 生命周期与总线归属

- `start()` 阻塞启动并按请求配置重建，可重复调用；成功仅表示驱动就绪，不表示链路建立。
- `status()` 保留最近一次启动结果，或后续 `configureLink()` / `restartAutoNegotiation()` 写失败导致的粘性 `WriteError`。`status() != Ok` 时，总线操作方法返回 `NotInitialized`，不访问总线、不修改输出；再次调用 `start()` 可重建并恢复。
- 正常断链不是读取错误：链路查询成功时可返回 `Down`；查询失败不改写输出。
- 链路配置支持自动协商或强制模式，能力由具体器件限定；显式重启协商不等待协商完成。
- 所有总线操作由调用方串行化。本接口没有线程创建、停止或 join 机制；与 [LwipPlatform](../lwip_platform/README.md) 配合时，由平台链路线程串行访问 PHY。

## 事件上下文

事件回调只表示“有事件需要处理”，不承诺已确认链路变化，也不保证事件仍 pending。具体驱动决定是否提供中断源；无中断源时由上层轮询。

- 回调可能在 ISR 中执行，只能做该上下文允许的通知，**不得访问 MDIO**。
- 实现须保证回调与 context 的更新不被 ISR 观察为半配置；关闭通知不等于复位 PHY。
- 中断电平可采样，但确认/清除事件会访问 MDIO，**只能在线程上下文调用**。
- 读取、确认与链路状态转换均由调用方在线程上下文完成；接口本身不替调用方管理板级 EXTI 或总线互斥。
