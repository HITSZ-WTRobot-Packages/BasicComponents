# PD 控制器

`PD` 提供基于误差差分的离散 PD 计算，不含积分、测速、驱动协议或硬件访问。包名虽为 PID_PD，实际算法只有 P、D 两项。

## 接入与计算契约

- cpkg 包名为 `libs::PID_PD`，见 [cpkg.toml](cpkg.toml)；manifest 未声明包依赖。公开入口为 [pid_pd.hpp](pid_pd.hpp)，计算实现位于 [pid_pd.cpp](pid_pd.cpp)。本包由宿主工程集成，不独立构建。
- 每次 `calc(ref, fdb)` 计算 `e = ref - fdb`，输出为 `Kp * e + Kd * (e - prev_error)`，再按 `abs_output_max` 对称限幅。
- 接口没有采样周期参数，也不会除以时间间隔；调用方负责固定更新节拍，并按实际周期配置离散增益。目标和反馈必须使用一致的单位、坐标方向与量程，输出单位由增益和下游执行器契约决定。
- 微分作用于误差，因此目标跳变也会进入 D 项；没有滤波、角度环绕处理或异常输入检测。

## 初始化、状态与限幅

- 默认增益和输出上限均为零；必须先构造或设置有效配置，才会得到有意义的控制输出。
- `abs_output_max` 应为有限的非负数。构造和 `setConfig()` 不取绝对值、不校验参数；零上限使有限输入的输出被夹为零，负上限不具备正常的对称限幅语义。
- 初始历史误差为零，首次计算的 D 项使用本次误差减零。`reset()` 清空历史误差、最近输入和输出，但保留配置；复位后的第一次计算同样如此。
- `setConfig()` 只替换配置，不清空历史或立即重算输出。切换控制对象、单位或运行阶段时，由调用方决定是否复位。
- 非有限输入不会返回错误码，也没有独立的失效状态；不能把限幅当作 NaN/Inf 检查或执行器安全保护。

## 资源与调用归属

对象按值保存配置及历史状态，不借用外设资源。`calc()`、`reset()` 与配置修改会改变同一实例；并发更新或在任务/ISR 间共享时，调用方必须串行化访问，包括读取输出。库不负责控制循环调度、急停或把结果发送到执行器。
