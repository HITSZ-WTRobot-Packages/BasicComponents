# MIT 风格 PD 控制器

`MITPD` 将位置误差和外部提供的速度误差组合成一个限幅输出。它不是 MIT 电机通信协议实现，也不从位置历史估算速度。

## 接入与单位

- cpkg 包名为 `libs::MIT_PD`，见 [cpkg.toml](cpkg.toml)；manifest 未声明包依赖。入口为 [mit_pd.hpp](mit_pd.hpp)，实现见 [mit_pd.cpp](mit_pd.cpp)。本包由宿主工程集成，不独立构建。
- 控制律为 `Kp * (p_ref - p_fdb) + Kd * (v_ref - v_fdb)`，随后按 `abs_output_max` 对称限幅；没有积分、前馈参数或误差差分。
- 位置给定/反馈必须单位一致，速度给定/反馈也必须单位一致，并与位置使用相容的方向约定。增益把两项映射到同一个输出单位；库没有规定必须使用弧度、转速、电流或力矩中的哪一种单位。
- 接口不接收采样周期、不进行时间积分或数值微分。反馈采样、速度计算、时间对齐与实际控制节拍均由宿主负责；库不补偿延迟，也不保证闭环稳定性。

## 配置、复位与边界

- 默认配置的增益和输出上限均为零；使用前应设置适合执行器的配置。
- 上限须由调用方设为有限非负值；构造和 `setConfig()` 不校验或取绝对值。零上限将有限输入的结果夹为零，负上限不具有正常的对称限幅语义。
- `calc()` 仅保存本次四个输入与输出，不使用前次误差或前次输出计算结果。首次计算无额外的历史初始化步骤。
- `reset()` 清零最近输入和输出，保留配置；下一次输出完全取决于新输入。`setConfig()` 只替换配置，不立即重算已保存的输出。
- 没有角度环绕、滤波、非有限输入检测或错误返回；限幅不能替代输入验证、位置限制与执行器保护。

## 对象与调用归属

实例按值持有配置和最近一次计算结果，不借用电机、总线或计时器。宿主负责输出发送和故障处理。同一实例上的计算、配置、复位与结果读取没有同步；任务之间或任务与 ISR 之间共享时，调用方必须安排串行访问。
