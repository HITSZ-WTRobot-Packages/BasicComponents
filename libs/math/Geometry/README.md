# 几何与姿态值类型

本包提供 `math` 命名空间中的欧拉角、四元数及三维位姿表达，不负责传感器融合、坐标系注册或硬件姿态采集。

## 接入与入口

cpkg 包名为 `Math::Geometry`，依赖 `Math::LinearAlgebra`，见 [cpkg.toml](cpkg.toml) 与 [线性代数说明](../LinearAlgebra/README.md)。实现均在 [Euler.hpp](Euler.hpp)、[Quaternion.hpp](Quaternion.hpp) 和 [Pose.hpp](Pose.hpp) 中，随宿主集成，不独立构建。常用别名提供 `float` 与 `double` 版本，数值类型应适合三角函数和归一化运算。

当前头文件存在接入边界，不能把所有入口视为已经可独立使用：

- `Quaternion.hpp` 的欧拉角构造实现使用 `unit::Deg`、带默认单位的 `EulerZYX<T>` 等来自 `Euler.hpp` 的声明，但自身未包含该头文件。直接使用四元数时，应先包含 `Euler.hpp`，再包含 `Quaternion.hpp`。
- `Pose.hpp` 表达了刚体变换意图，但当前变换、求逆和复合实现调用 `rot.rotate(...)`，而本包四元数实际提供的是 `rotateVector(...)`；求逆还使用了当前 `Vec` 未提供的一元负号。因此这些位姿运算不能视为现有源码可用的能力。本说明不提供绕过该问题的替代实现。

## 角度、旋转与坐标约定

- `EulerZYX<T, AngleUnit>` 明确采用右手系，ZYX（yaw-pitch-roll）约定；字段顺序为 `roll`、`pitch`、`yaw`，分别对应 X、Y、Z 轴。默认单位为弧度，`unit::Deg` 类型使用角度，转换接口显式切换单位。
- 四元数字段和四标量构造参数顺序为 `w, x, y, z`，默认值为单位旋转。乘法使用 Hamilton 乘积；欧拉角转换公式按上述 ZYX 约定实现。
- `rotateVector(v)` 的实际计算为 `t = 2 * (q.xyz × v)`，结果为 `v + w*t + q.xyz × t`，以单位四元数为旋转前提。这里没有规定世界系、机体系、ENU/NED 或传感器安装方向；这些语义和位置单位必须由消费者统一。
- 位姿类型把 `pos` 作为平移、`rot` 作为旋转，并在源码中注明复合意图为 `T_ac = T_ab * T_bc`；这不消除上面列出的当前实现不匹配。

## 归一化与数值边界

- 四标量四元数构造会立即归一化，零模长没有保护。分量公开可写，直接修改后不会自动维持单位长度；调用方须维护有效旋转状态。
- 四元数乘法、标量乘法及共轭均通过四标量构造返回，因此会归一化结果。标量乘法不是保留模长的普通四元数数乘；`inverse()` 也不能当作任意非单位四元数的通用代数逆使用。零或非有限输入没有错误返回。
- 欧拉角转四元数先把角度输入换算为弧度。四元数转欧拉角在 `abs(sinp) >= 1` 时将 pitch 置为带符号的 π/2，但并未消除万向节锁或保证角度轨迹连续；该转换主要用于配置、日志与显示。
- 位姿默认值为零平移和单位旋转；复制已有四元数到位姿不会额外归一化或验证它。

## 资源与并发

这些类型按值保存分量，不拥有设备或借用的外部缓冲区，也没有内部同步。宿主负责对象寿命、单位/坐标系一致性和无效数值处理；对同一对象的修改及跨任务、任务/ISR 读取必须安排同步，不能据值类型接口推断硬实时或并发安全保证。
