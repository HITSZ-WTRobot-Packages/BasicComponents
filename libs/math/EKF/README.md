# 扩展卡尔曼滤波计算核心

`math::ekf::EKF<T, StateDim>` 保存状态与协方差并执行预测、观测更新的矩阵计算。它不是预置运动模型、传感器模型或完整的融合任务。

## 包、类型与初始化

- cpkg 包名为 `Math::EKF`，依赖 `Math::LinearAlgebra`，见 [cpkg.toml](cpkg.toml) 与 [线性代数说明](../LinearAlgebra/README.md)。入口和实现均为 [EKF.hpp](EKF.hpp)，由宿主工程集成，不独立构建。
- 状态 `x` 为 `Vec<T, StateDim>`，`P`、`Q` 为 `StateDim × StateDim` 矩阵，全部按值保存在实例中。维度固定在编译期，`T` 应选择适合矩阵求逆的浮点类型；库不进行整数到浮点的自动算法替换。
- 默认构造使 `x`、`P`、`Q` 为零，不会生成合理的初始不确定度或噪声参数。使用前通过构造参数或公开成员设置应用所需的初值；没有专用复位方法，重新初始化这些成员由宿主负责。

## 模型与更新职责

预测调用方先计算非线性模型输出 `predicted_x = f(x, u, dt)` 及该次线性化的状态 Jacobian `F`，再调用 `predict(predicted_x, F)`。库仅执行：

- `x = predicted_x`
- `P = F * P * F.transpose() + Q`

库不调用 `f`，没有输入控制量或采样周期参数，也不自动离散化过程噪声。周期、单位、状态分量顺序、模型线性化点以及每步 `Q` 的含义必须由消费者统一；改变周期后需要由消费者重新确认模型和噪声。

观测更新的 `MeasDim` 也在编译期确定，可以在同一实例上选择不同测量维度的更新。调用方提供：

- 创新 `y = z - h(x)`，而不是原始观测 `z`；角度环绕或其他残差定义应在这里处理。
- 当前线性化点的 `H`，维度为 `MeasDim × StateDim`。
- 本次观测噪声协方差 `R`，维度为 `MeasDim × MeasDim`。

库计算 `S = H * P * H.transpose() + R`、`K = P * H.transpose() * S.inverse()`，然后更新 `x += K * y` 和 `P -= K * H * P`。模型推进、观测有效性、时间对齐及预测/更新的调用顺序属于宿主职责；没有自动测量门限、异常值剔除或状态约束投影。

## 协方差与失败边界

- 调用方负责使初始 `P`、过程噪声 `Q` 和观测噪声 `R` 与模型、单位和不确定度一致，并满足应用所需的对称性、半正定性及创新协方差可逆条件；库不检查这些条件。
- `S.inverse()` 沿用线性代数包的限制：1～4 阶无奇异检查，更高阶使用无选主元的 Gauss–Jordan 消元并可能触发主元断言。故状态维度不是求逆维度，真正触发这条边界的是测量维度；可逆性本身也不保证高阶消元不需换行。
- 协方差更新使用上述直接减法形式，不是 Joseph 形式；没有自动对称化、正定性修复或数值稳定性保证。
- `predict()`、`update()` 不返回成功状态；非有限输入或求逆异常没有滤波级恢复路径。消费者必须在接收测量、准备模型和使用输出时处理有效性，不能把调用返回当作估计可信的证明。

## 生命周期与并发

实例不持有模型回调、传感器或外部缓冲区；调用方提供本次计算所需的值并管理滤波器生命周期。矩阵临时量随模板维度增长，应按宿主的存储与调用栈条件选择维度。同一实例上的预测、更新、公开成员修改和输出读取没有锁，任务之间或任务/ISR 之间共享时必须串行化，避免将不同时间点的状态与协方差混用。
