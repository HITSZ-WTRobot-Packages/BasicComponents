# 固定维度线性代数

本包在 `math` 命名空间提供小规模向量与矩阵值类型，用于控制、几何和状态估计，不是动态维度或带数值诊断的通用线性代数库。

## 包与数据表示

- cpkg 包名为 `Math::LinearAlgebra`，无包依赖，见 [cpkg.toml](cpkg.toml)。入口为 [Vec.hpp](Vec.hpp) 与 [Mat.hpp](Mat.hpp)，实现位于头文件中；随宿主工程集成，不独立构建。
- `Vec<T, N>` 和 `Mat<T, Rows, Cols>` 的维度由模板决定，使用对象内部的固定大小存储；矩阵通过 `m[row][col]` 访问。二维、三维向量有具名分量特化，不应把所有维度都当成同一种数组布局。
- 内置别名覆盖 `float`、`double` 的常用向量及部分方阵。模板没有强制浮点类型，但范数、归一化、逆矩阵等含除法或平方根的数值计算应选择合适的浮点类型；使用整数不会自动提升为浮点算法。
- 同形加减、矩阵乘法与矩阵乘向量的维度由函数签名约束；单位矩阵、迹、行列式和求逆要求方阵。行列式仅实现 1～4 阶，更高阶调用会触发编译期限制；这不等于矩阵乘法或求逆也限于四阶。

## 数值与索引边界

- 默认向量和矩阵为零；单位矩阵需要显式创建。索引不检查越界：通用向量和矩阵直接访问内部存储，二维/三维特化对超范围下标也不会报告错误。调用方必须使用合法维度和下标。
- 标量除法不检查零除数；向量归一化直接除以范数，零向量没有特殊处理。调用方负责非零范数、有限输入及应用所需的数值容差。
- 1～4 阶 `inverse()` 使用倒数或伴随矩阵/行列式公式，不检查奇异性或近奇异性，也不返回求逆状态。不能把返回一个矩阵当作成功判据。
- 更高阶 `inverse()` 使用 `inverse_gj()`；后者也可显式调用，采用不换行、不选主元的 Gauss–Jordan 消元。每步仅用断言要求当前主元绝对值大于 `1e-9`，没有秩检测、条件数估计或恢复路径；可逆矩阵也可能因需要换行而失败。关闭断言后仍会继续除以该主元。
- 二维向量的 `rotate(yaw)` 使用弧度，令 `c = cos(yaw)`、`s = sin(yaw)`，结果为 `(c*x - s*y, s*x + c*y)`；`perp()` 为 `(-y, x)`。三维叉积使用通常的分量公式。库不为向量附加世界系/机体系或物理单位标签。

## 存储与调用归属

运算返回值对象或修改当前对象，不借用外部缓冲区。对象及计算中的固定维度临时量随维度增长，宿主应据实际维度安排存储和调用栈；没有动态尺寸管理器。没有锁或共享状态调度，同一对象被修改时，跨任务或任务/ISR 的访问需由调用方同步。数值有效性、算法收敛与硬件浮点性能均不是本包提供的保证。
