# printf

`libs::printf` 是嵌入式轻量格式化实现，入口为 [printf.h](printf.h)，实现为 [printf.c](printf.c)。[cpkg.toml](cpkg.toml) 未声明其他包依赖。由宿主项目集成源码，不是独立可执行程序，也不自动初始化 UART、RTOS 或任何输出设备。

## 输出接入与名称边界

使用 `printf_()` / `vprintf_()` 时，宿主必须实现头文件声明的 `_putchar(char)`；C++ 实现需保持该声明的 C 链接。输出逐字符同步调用，不提供队列、DMA 缓冲、换行转换或输出错误返回。`fctprintf()` 可为单次调用传入字符回调和用户指针，回调及其资源必须在整个调用期间有效，不能传空回调。

头文件通过宏把 `printf`、`sprintf`、`snprintf`、`vsnprintf`、`vprintf` 替换为带下划线的实现名；这些宏会影响后续代码，不是透明地替换整个标准库。与标准格式化头文件及其他库共存时，宿主需要管理包含顺序和宏影响范围；具体支持的格式以实现为准，不应当作完整 libc 格式化契约。

设备输出包装会过滤值为零的字符，包括结尾终止符。因此 `%c` 的零字符虽然计入格式化长度，却不会传给 `_putchar` 或字符回调。回调返回类型为 `void`，返回字符数不代表底层串口实际发送成功。

## 缓冲区、返回值与错误边界

- 优先使用带容量的 `snprintf_()` / `vsnprintf_()`。`count` 包含结尾零字符空间；非空缓冲区且 `count > 0` 时最多保留 `count - 1` 个输出字符并写入终止符。`count == 0` 时不写入。
- 返回值是本来应生成的字符数，不含终止符，而非实际保留长度；非负返回值大于等于 `count` 表示空间不足。空缓冲区指针走计数路径，不写入，可用于估算长度。调用方应把预期输出长度限制在返回类型 `int` 可表示的范围内。
- `sprintf_()` 不限制目标长度，调用方必须提供足够空间；实现不会替它检测溢出。格式串、`%s` 字符串和可变参数的类型/生命周期必须有效，不提供空字符串指针兜底或格式参数类型校验。
- 未支持或被关闭的格式没有可靠的错误返回协议，不应依赖它们仍按标准语义读取参数或生成结果。

## 存储、浮点与并发

格式化状态和数字转换临时缓冲区位于调用栈中，实现没有动态分配输出缓冲区。整数和浮点转换的内部缓冲区默认分别为 32 字节，由 `PRINTF_NTOA_BUFFER_SIZE`、`PRINTF_FTOA_BUFFER_SIZE` 控制；它们不是外部输出缓冲区容量，应按所需数字格式与栈空间配置。

默认启用 `%f` 及指数/自适应浮点格式，默认浮点精度为 6。编译 `printf.c` 时可定义 `PRINTF_DISABLE_SUPPORT_FLOAT` 关闭浮点支持，或定义 `PRINTF_DISABLE_SUPPORT_EXPONENTIAL` 仅关闭指数相关支持；`PRINTF_DEFAULT_FLOAT_PRECISION` 可调整默认精度。定义 `PRINTF_INCLUDE_CONFIG_H` 会额外包含由宿主提供的 `printf_config.h`，仅在调用文件里定义宏不会改变已编译的实现。

独立调用使用局部格式化状态，但共享目标缓冲区、`_putchar`、回调及设备都没有由本包加锁。并发输出可能按字符交错；需要完整日志记录原子性时由宿主串行化整个调用。ISR 可用性取决于输出后端是否阻塞/使用锁、缓冲区归属、栈和执行时长，不能从可重入格式化核心推导 ISR 安全或实时性保证。
